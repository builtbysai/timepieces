# Timepieces

Every way to read the time — by Hans Sai.

Live: https://builtbysai.com/timepieces/

## Pieces

- **Meridian** (`meridian/`) — analog reimagined: one unbroken line from center
  through hour, minute, and second hands.
- **Digits** (`digits/`) — monumental digital time with a live seconds bar.
- **Word** (`word/`) — the time as a spoken sentence.
- **Hex** (`hex/`) — the background is the time as a hex color (#HHMMSS).
- **Spiral** (`spiral/`) — twelve hours per turn; the coil draws the day.
- **Tide** (`tide/`) — each minute is one breath; color follows the hour's temperature.
- **Binary** (`binary/`) — a clock of stones.
- **Erode** (`erode/`) — a black monolith on black ground, eroding as the day passes.
- **Flicker** (`flicker/`) — six nixie tubes showing real time, HH MM SS.
- **Orbit** (`orbit/`) — the solar system as a clock: three planets keep the time.
- **Shadow** (`shadow/`) — a sundial for the digital age; drag to scrub time.
- **Rings** (`rings/`) — the day as a tree cross-section: one ring per hour, the current hour growing as an arc.
- **Progress** (`progress/`) — the day as wavy contour lines, after Hans's "Progress is not Linear" poster: one line per hour, drawn as you live it, the pen is now.

All client-side, no dependencies.
